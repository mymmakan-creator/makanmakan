CYD MP3 Player

Install the LVGL music-player firmware on the original CYD ESP32-2432S028R board with the ILI9341 240×320 display.

ESP32ILI9341LVGL 9.2.2SD card audio
Important: this installer erases the ESP32 flash and replaces the current firmware. Back up anything you need first. Use a data-capable USB cable and Chrome or Edge on desktop. The SD card's music files are not erased by flashing internal ESP32 memory.

Before installing

  1. Use the original CYD ESP32-2432S028R with ILI9341 display (one micro-USB port).
  2. Connect the board directly to your computer with a USB data cable.
  3. Click Install, choose the serial port, and confirm the prompts.
  4. After flashing, insert a FAT32 microSD card with music in /MP3/, then reset the board.

The firmware is built automatically by GitHub Actions from the upstream CYD_MP3Player source with ESP32 core 2.0.17 and the project's LVGL configuration. If a build fails, the installer must not be treated as up to date.
